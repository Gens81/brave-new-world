Brave New World v3.0 Changelog


Battle Changes


* New “Choreography” Dance command rework (Sir Newton Fig)
   * Choosing to “change the background” and choosing to “repeat the background” with Dance gives different results
   * Dance no longer causes the player to lose control of Mog/Gogo
   * Mog/Gogo no longer stumble
   * Mog has “fast fall” by default when using Jump
   * Moogle Charm is gone forever
   * Added an event to explain the new Dance command after recruiting Mog (Fëanor)
   * The current battle terrain is shown in yellow text in the Dance menu (Fëanor)
* Changed 100+ animations, and added brand new animations for some abilities (Khaos)
   * Animations better indicate their elemental properties and effects
   * Characters jump to indicate that an effect cures many or all negative statuses
   * Various long animations have been sped up significantly
   * Duplicated animations have been removed
* Enemies flash red when performing a counter-attack (Fëanor)
* When your cursor is on a non-boss enemy, press ‘X’ for HP/MP information (Bropedio)
* When your cursor is on any enemy, press ‘Y’ for a list of active statuses (Bropedio)
* Scan has been reworked to give hints about enemy behavior (only for non-bosses) in addition to listing elemental weaknesses (Bropedio, Gens, Khaos)
* Press ‘Select’ button in battle to cycle between: ATB bar, current/max HP, and current/max MP (Fëanor)
* Summoning espers is possible for characters with X-Magic (Fëanor)
* “Summon available” icon added next to Magic command during battle (Sir Newton Fig)
* Item menu will arrange the inventory to have more relevant items at the top of the list during battle (Ryo_Hazuki)
* New graphics added to distinguish characters affected by Zombie status from those with only the Undead status (Toadstyle, Khaos)
* Wrexsoul’s battle has been reworked (Khaos)
   * Gi Nattak applies the Condemn status, indicating who is possessed
   * MP damage no longer trivializes the fight
   * Cyan joins the party for the battle (Fëanor)
* The final battle with the three tiers has been remastered (Khaos, Ryo_Hazuki)
   * Final enemies flash when they attack or counter-attack
   * New graphics indicate if a final enemy is dead
   * Final enemies have new names
   * Final enemies are sketchable
   * Final fight background with Kefka changed to be “Brave New World” themed (Gens)


Balance Changes


* Removed MP bonus from Radiant Gown, added Auto-Shell
* Brushes reworked
   * Light Brush may cast Safe
   * Monet Brush may cast Shell
   * Dali Brush may cast Reflect
   * Ross Brush may cast Haste
   * Removed X-fight from brushes, but raised proc rate to 50% and increased battle power
* Sketch can’t miss
* Bahamut summon spell power raised to 150
* Magus Rod (formerly Mythril Rod) may cast Rasp (betting reward updated accordingly)
* Removed HP bonus from Royal Jacket, added “spellcast rate up” and Auto-Safe
* Claws reworked
   * Light Claw (formerly Spirit Claw), Ocean Claw and Frostgore provide counter-attack
   * Poison Claw, Hell Claw and Stormfang provide HP bonuses
* Hell Claw Chest in Zozo replaced with Ninja Star (and added a secret Hell Claw backdoor) (Fëanor)
* Killing Doomgaze unlocks all Blitz abilities (by talking to Duncan) (Fëanor)
* Soul Sabre’s spellcast rate increased from 25% to 50%
* Exploder (player version) leaves the caster with 1 HP (Sir Newton Fig)
* Siren Song may set Muddle and Berserk
* Added anti-human flag to Morning Star


Other Changes and Features


* Optional “Diary” patch is available (Ryo_Hazuki, Gens)
   * Includes a full Bestiary with graphics and details for every monster
   * Includes all Scan behavior hints, as well as Diary-exclusive boss hints
   * Includes a music player (Madsiur, ported by Ryo_Hazuki)
   * Includes wallpaper gradient switch
   * Includes font switching between FF6 Standard and FF6 Advance
   * Note that this patch will expand ROM size to 4MB
* “Advanced Diary” patch is available in the unlockme once you beat the game
   * Instead of listing hints, the advanced diary gives a complete description of all enemy scripts, including bosses
* Managing magicite and ELs is more streamlined (Ryo_Hazuki)
   * Yellow up-arrows appear on the main menu to indicate that a character has unspent ELs 
   * Selecting magicite equipped by another character allows you to transfer it
   * Selecting the same magicite twice automatically unequips it
   * Status screen shows how much a stat has been raised by using ELs
   * EL number in the main menu grays out when no magicite is equipped
   * EL batch spending has been added (Fëanor)
* LV number in the main menu grays out when XP gain is off (Ryo_Hazuki)
* The Rage menu outside of battle has been overhauled (Ryo_Hazuki, Gens)
   * A Rage details screen has been added, which displays: Status resistances, innate statuses, elemental resistances and elemental weaknesses (press ‘Y’ to access)
   * Rage ability descriptions have been added
   * Rage checklist has been added (Novalia Spirit, ported by Fëanor)
* World of Balance Rage formations unlock after completing the Floating Continent (Seibaby)
* Characters are no longer automatically equipped in some cases, instead the main menu opens before the following fights: (Fëanor)
   * Cranes
   * Phunbaba 3
   * Tentacles
   * Wrexsoul
   * After selecting "Go to the Floating Continent"
* Stamina renamed to Spirit
* Holding the ‘B’ button will advance dialog text, except for choices (Fëanor)
* New Locke scene in Returners Hideout (Fëanor)
* Spell and ability descriptions have been updated (Gens)
* New Slots menu added to the skills menu (Ryo_Hazuki)
* Power and targeting information for many abilities is available in menus by holding the ‘Y’ button (Ryo_Hazuki)
* Warping out of Ancient Castle and Ancient Cave is enabled (Khaos)
* Some accessibility features have been added:
   * Reduced repeated flashing effects for Bum Rush, Schiller, and Volt Array (formerly Diffuser)
   * Reduced mosaic effect when poisoned (Gens)
   * Half ATB is refunded on incorrect blitz input (Sir Newton Fig)
   * Bushido gauge speed capped when reaching 6 (Fëanor)
   * Each bridge guard in Gogo’s Cave can knock you off at most once (Khaos)
   * Factory doors in Kefka’s Tower are more visible (Khaos)
* Added custom title screen (Ryo_Hazuki, Khaos)
* Added custom credits to the introduction
* Added a special message to the end screen
